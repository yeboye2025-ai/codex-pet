# Pet Whisper

Pet Whisper is a photo-first dog emotion interpretation web app. It lets a dog
owner upload a single image, receive a structured AI-assisted read of visible
behavior cues, revisit saved results, and generate a shareable card.

## Getting Started

1. Install dependencies with `npm install`
2. Copy `.env.example` to `.env.local`
3. Set `OPENAI_BASE_URL`, `OPENAI_API_KEY`, and `OPENAI_MODEL`
4. Start the app with `npm run dev`

## Testing

- `npm test`
- `npm run test:e2e`

## V1 Features

- Single-photo dog mood analysis
- Structured scientific interpretation and inner monologue
- Favorites
- History timeline
- Share card generation
